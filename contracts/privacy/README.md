# Privacy and ZK Verification Contracts

This directory contains zero-knowledge proof verification contracts for privacy-preserving compliance.

## Contracts

- `ZKVerifierIntegrated.sol` - Wraps the five snarkjs PLONK verifiers (whitelist, blacklist, jurisdiction, accreditation, compliance aggregation): signal range check, proof cache bound to the verifier instance, typed routes and the attestation router
- `PrivacyManager.sol` - Whitelist root registry and wallet binder; trusted attestation issuer keys, attestation policies and the attestation record per wallet
- `DynamicListManager.sol` - Dynamic list management
- `verifiers/` - Generated by `npm run setup:zk` (committed; CI asserts they reproduce)

## Interfaces

- `IZKVerifier.sol` - The ZKVerifierIntegrated entries PrivacyManager consumes
